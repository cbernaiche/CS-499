Capstone Project

Liar's Dice

C++ Visual Studio SQLite Algorithms Database

Hello everyone, my name is Chris Bernaiche and I am currently a computer science student at SNHU.

For this capstone class, I had to take a previous project and enhance it in three ways: software design and engineering, algorithms and data structures, and databases.

The project I chose was a Liar's Dice game that I had made in a simple form in a previous class. When I first developed this game, it was made in Visual Studio Code because I was tasked with creating simple code with minimal debugging.

To start my enhancements on this game, I decided to move it to Visual Studio because it provided more tools that would help me make the project more advanced.

I added more algorithms to make the game have five rounds rather than just one round. I also added a way to have the rules appear at the beginning of the game. Lastly, I added a database that stores player statistics and awards.

Database Enhancement

Database

Within the database, I created two main sections: player statistics and inventory. The player statistics section stores information about each player's performance, including the amount of wins each player has.

Player Statistics

The player statistics table keeps track of player information and the number of wins each player has earned.

Player Awards & Inventory

Players can earn awards for getting their first win, building win streaks, reaching win milestones such as 10 wins, 20 wins, or more, and reaching bluff milestones. These rewards are stored within the inventory section of the database.
